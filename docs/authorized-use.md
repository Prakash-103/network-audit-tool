## 3. Acceptable Use Scenarios

This software is legitimately and safely used for:
1. **Enterprise Infrastructure Audits**: Verifying device compliance against corporate standards and golden configurations.
2. **Pre-Migration & Post-Cutover Auditing**: Documenting Layer 2/Layer 3 topology, port channels, VLANs, and routing state before and after network maintenance.
3. **Regulatory & Compliance Verification**: Generating formal Excel audit workbooks for standards such as PCI-DSS, ISO 27001, SOC 2, and CIS Benchmarks.
4. **Multi-Vendor Baseline Documentation**: Standardizing multi-vendor network inventory across Cisco, Arista, Juniper, Fortinet, Palo Alto, and Aruba platforms.
